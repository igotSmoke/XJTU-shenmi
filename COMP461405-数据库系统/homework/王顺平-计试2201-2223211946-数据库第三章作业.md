## 问题
1、以下定义的是某汽车修理厂管理系统数据库，其中加下划线的为关系模式主键，斜体字为外键。该修理厂雇用若干名修理工并划分为不同的班组，汽车维修以班组为单位进行，每个班组安排一名修理工作为组长负责分配给该组的汽车维修事宜。
- 修理工(<u>工号</u>，姓名，年龄，参加工作时间，*班组号*)  
- 班组(<u>班组号</u>，人数，*组长工号*) 
- 汽车(<u>车牌号</u>，车主姓名，车型，联系电话)
- 维修(<u>维修记录编号</u>，*车牌号*，*班组号*，维修时间，收费)
**试对这个关系数据库写出如下SQL查询：**
1.查询该修理厂划分的维修班组总数

```sql
SELECT 
  COUNT(班组号) AS 班组总数
FROM
  班组;
```

2.查询各维修班组的班组号及其组长姓名
```sql
SELECT
  b.班组号,
  x.姓名 AS 组长姓名
FROM
  班组 b
JOIN
  修理工 x ON b.组长工号 = x.工号;

```     
3.查询车牌号为“V0075”的汽车在“2019-01-01”至“2019-12-31”期间由修理工“E029”所在班组进行维修的费用总额

```sql
SELECT
  SUM(w.收费)
FROM
  维修 w
WHERE
  w.车牌号 = 'V0075'
  AND w.维修时间 BETWEEN '2019-01-01' AND '2019-12-31'
  AND w.班组号 = (
    SELECT x.班组号 FROM 修理工 x WHERE x.工号 = 'E029'
  );
```
  
4.将修理工“E010”所在分组编号调整为“T03”
```sql
UPDATE  修理工
SET 班组号 = 'T03'
WHERE 工号 = 'E010';
```  

2、以下定义的是某手机话费充值卡管理系统数据库，其中加下划线的为关系模式主键，斜体字为外键。每张充值卡通过卡号及密码为手机号码充值，一张充值卡只能为一个手机号码充值且一次充值过程必须消费完卡上的所有金额。每个手机号码只属于一个机主，而每位机主可以拥有多个手机号码。
- 充值卡(<u>卡号</u>，密码，面额，是否已售出)
- 手机(<u>手机号码</u>，开户时间，开户地点，*机主编号*)
- 充值(<u>*卡号*</u>，*手机号码*，充值时间)
- 机主(<u>机主编号</u>，姓名，身份证号码，联系地址，联系方式)
**对这个关系数据库写出如下SQL查询：**
1.查询尚未售出(是否已售出属性取值为“否”)的充值卡张数 

```sql
SELECT
  SUM(卡号)
FROM
  充值卡
WHERE
  是否已售出 = '否';
```

2.查询“刘”姓手机机主的姓名及持有的手机号码

```sql
SELECT
  j.姓名,
  s.手机号码
FROM
  机主 j
JOIN
  手机 s ON s.机主编号 = j.机主编号
WHERE
  j.姓名 like '刘%';
```
3.查询开户地点为“西安交通大学”的所有手机号码在“2019-11-01”至“2019-11-30”期间的充值总额
```sql
SELECT
  SUM(czk.面额)
FROM
  充值卡 czk
JOIN
  充值 c ON c.卡号 = czk.卡号
JOIN
  手机 s ON c.手机号码 = s.手机号码
WHERE
  s.开户地点 = '西安交通大学'
  AND
  c.充值时间 BETWEEN '2019-11-01' AND '2019-11-30';
  
```
4.将卡号为“SX010323”的充值卡面额增加一百元 
```sql
UPDATE 充值卡
SET 面额 = 面额 + 100
WHERE 卡号 = 'SX010323'
```
3、以下是某学生食堂就餐卡管理系统中的部分表，其中加下划线的属性为主键，斜体字属性为外键，每个学生只可办理一张就餐卡。
- 学生(<u>学号</u>，姓名，性别，班级，出生年月)
- 就餐卡(<u>卡号</u>，学号, 开户日期，失效日期，密码，余额，每日消费限额)
- POS终端(<u>POS编号</u>，地理位置)
- 消费(<u>*卡号*</u>，<u>*POS编号*</u>，消费日期，消费金额)
- 充值(<u>*卡号*</u>，充值时间，金额)
**请写出关于这些表的如下SQL查询：**
1.查询卡号为“053021”的就餐卡余额及每日消费限额
```sql
SELECT
  余额,
  每日消费限额
FROM 就餐卡
WHERE 卡号 = '053021';
```
2.查询编号为“018”的POS终端2010年12月的总收入 
```sql
SELECT
  SUM(消费金额) AS 总收入
FROM 
  消费
WHERE POS编号 = '018'
  AND  消费日期 BETWEEN '2010-12-01' AND '2010-12-30';
```
3.查询“张蓓”同学2019年10月11日在编号为“029”的POS终端上的消费次数
```sql
SELECT
  COUNT(*) AS 消费次数
FROM 消费 x
JOIN 就餐卡 j ON j.卡号 = x.卡号
JOIN 学生 xs ON xs.学号 = j.学号
WHERE xs.姓名 = '张蓓'
  AND x.POS编号 = '029'
  AND x.消费日期 = '2019-10-11';
```
4.查询曾经在“西八食堂”(地理位置)就餐过的学生学号及姓名

```sql
SELECT
  xs.姓名,
  xs.学号
FROM 学生 xs
JOIN 就餐卡 jc ON jc.学号 = xs.学号
JOIN 消费 xf ON jc.卡号 = 消费.卡号
JOIN POS终端 po ON po.POS编号 = xf.POS编号
WHERE xf.地理位置 = '西八食堂';
```
