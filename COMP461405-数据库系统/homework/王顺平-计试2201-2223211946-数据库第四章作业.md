#### 一、判断以下关系模式最高属于第几范式，并解释原因。
R1(A,B,C,D)，F ={ A→B, BC→D }  
R2(A,B,C,D)，F ={ BC→D, AB→C, D→C, AC→B }  
R3(A,B,C,D)，F={AC→B,AC→D}     
R4(A,B,C,D)，F={BC→A,A→B,D→C} 
R5(A,B,C,D)，F={A→B,B→C }           
R6(A,B,C,D,E)，F={E→D,D→A,A→E,B→A}  

1. **R1(A,B,C,D)，F = {A→B, BC→D}**  
   - **候选键**：AC  
   - 存在部分依赖（A→B，B仅依赖候选键AC的部分属性A）。  
   - **最高范式**：1NF  

2. **R2(A,B,C,D)，F = {BC→D, AB→C, D→C, AC→B}**  
   - **候选键**：AB、AD、AC  
   - 所有属性都是主属性，满足2NF。
   - 所有属性都是主属性，显然也满足3NF。
   - 存在左侧非超键的依赖，不满足BCNF。
   - **最高范式**：3NF  

3. **R3(A,B,C,D)，F = {AC→B, AC→D}**  
   - **候选键**：AC  
   - 所有属性完全依赖候选键AC，且函数依赖左部为超键。  
   - **最高范式**：BCNF  

4. **R4(A,B,C,D)，F = {BC→A, A→B, D→C}**  
   - **候选键**：BD、AD  
   - 候选键BD中，D→C导致C部分依赖BD，存在部分依赖。  
   - **最高范式**：1NF  

5. **R5(A,B,C,D)，F = {A→B, B→C}**  
   - **候选键**：AD  
   - A→B导致B部分依赖候选键AD中的A，存在部分依赖。  
   - **最高范式**：1NF  

6. **R6(A,B,C,D,E)，F = {E→D, D→A, A→E, B→A}**  
   - **候选键**：BC  
   - B→A导致A部分依赖候选键BC中的B，存在部分依赖。  
   - **最高范式**：1NF  


#### 二、给定关系模式R(A,B,C,D,E)，F={AB→C,C→E,D→A}，判定分解：
ρ={R_1(AD), R_2(BCD), R_3(CE) }
1)是否无损连接    
2)是否保持函数依赖F    

**是否无损连接**  
      
     1. 构建初始表格（行代表子模式，列代表属性）：  
        - R₁(AD): a₁, b₁₂, b₁₃, a₄, b₁₅  
        - R₂(BCD): b₂₁, a₂, a₃, a₄, b₂₅  
        - R₃(CE): b₃₁, b₃₂, a₃, b₃₄, a₅  
     2. 应用函数依赖：  
        - AB→C：无事发生。  
        - C→E：将 R₂ 的 E 从 b₂₅ 改为 a₅。  
        - D→A：因 R₁ 和 R₂ 的 D 均为 a₄，将 R₂ 的 A 从 b₂₁ 改为 a₁。  
     3. 结果：R₂ 行变为全 a（a₁, a₂, a₃, a₄, a₅），存在全 a 行。  
   
故分解是无损连接。

**是否保持函数依赖 F**  
   
     - **D→A**：在 R₁(AD) 中保持。  
     - **C→E**：在 R₃(CE) 中保持。  
     - **AB→C**：无子模式同时包含 AB 和 C，无法直接保持，也无法通过其他依赖推导。  

不保持函数依赖 F。


#### 三、设有关系模式R(A,B,C,D,E)，F={AB→C,AC→E,C→B,D→C,E→C}，判定分解：
={R_1(ABC), R_2(AE), R_3(BE), R_4(CD), R_5(DE)}
1)是否无损分解    
2)是否保持函数依赖F    

**三、分解判定分析**

**是否无损分解**  

      构建初始矩阵（行代表子模式，列对应属性A,B,C,D,E）：  
        - R₁(ABC): a₁, a₂, a₃, b₁₄, b₁₅  
        - R₂(AE): a₁, b₂₂, b₂₃, b₂₄, a₅  
        - R₃(BE): b₃₁, a₂, b₃₃, b₃₄, a₅  
        - R₄(CD): b₄₁, b₄₂, a₃, a₄, b₄₅  
        - R₅(DE): b₅₁, b₅₂, b₅₃, a₄, a₅  

         应用函数依赖：
        - C→B：将 R₄ 的 B 从 b₄₂ 改为 a₂。  
        - D→C：将 R₅ 的 C 从 b₅₃ 改为 a₃。  
        - E→C：将 R₂ 和 R₃ 的 C 均改为 a₃。  
        - AC→E：将 R₁ 的 E 从 b₁₅ 改为 a₅（通过 R₂ 的 A=a₁ 和 C=a₃ 推导）。  
      最终矩阵中无全 a 行。  

分解是有损的。

**是否保持函数依赖 F** 

     - AB→C：在 R₁(ABC) 中保持。  
     - C→B：在 R₁(ABC) 中保持。  
     - D→C：在 R₄(CD) 中保持。  
     - AC→E 和 E→C：无子模式同时包含 AC 或 E 与 C，无法直接保持,也无法通过依赖推导。 

不保持函数依赖 F。


#### 四、给定关系模式R(A, B, C, D)，F={A→B, B→A, C→AB, D→AB, CD→A}。
1)求F的最小函数依赖集$F_{min}$； 
2)求R的所有候选键； 
3)将R分解为一组3NF，且既无损联结又保持函数依赖； 


**求最小函数依赖集 \( F_{\text{min}} \)**   
     1. 分解右部为单属性  
         F = \{ A→B, B→A, C→A, C→B, D→A, D→B, CD→A \} .  
     2. 消除左部冗余属性  
        -  CD→A  可简化为  D→A （因  D→A  已存在），删除  CD→A .  
     3. 消除冗余依赖  
        -  C→A  冗余（由  C→B  和  B→A  推导），删除.  
        -  D→A  冗余（由  D→B  和  B→A  推导），删除.  

得到结果
\[
   F_{\text{min}} = \{ A→B, B→A, C→B, D→B \}.
\]

**求所有候选键**  
   - **候选键**： CD .  
   都在左边的是CD,不在的为空，求闭包发现是U，故CD。


**3NF分解（无损且保持依赖）**    
     1. 为每个函数依赖创建子模式：  
        -  $R_1(A,B)$ （覆盖  A→B, B→A ）  
        -  $R_2(C,B)$ （覆盖  C→B ）  
        -  $R_3(D,B)$ （覆盖  D→B ）  
     2. 包含候选键的子模式：  
        -  $R_4(C,D)$ （确保无损连接）  
   - 结果：  
     \[
    \{ R_1(A,B), R_2(C,B), R_3(D,B), R_4(C,D) \}.
     \]
  


#### 五、设有关系模式R(A,B,C,D,E,G,H),
F={A→B,B→E,CD→B,CDE→A,G→AEH,H→EG}
1) 试求F的最小函数依赖集FMIN； 
2) 试求R的所有候选键； 
3) 试将R分解成3NF模式集，要求分解无损连接且保持函数依赖; 


**最小函数依赖集 \( F_{\text{MIN}} \)**    
分解右部为单属性  
        \[
        F = \{ A→B, B→E, CD→B, CDE→A, G→A, G→E, G→H, H→E, H→G \}.
        \]  
消除冗余依赖  
        - 删除  G→E （由  G→H  和  H→E  推导）。  
        - 删除  H→E （由  H→G  和  G→E  推导）。  
 合并左部相同依赖  
        -  G→A  和  G→H 合并为  G→AH 。    
结果：  
     \[
     F_{\text{MIN}} = \{ A→B, B→E, CD→B, CDE→A, G→AH, H→G \}.
     \]

**候选键**  
      都在左边的有CD,左右都有的有B, H ,G ,逐个加入检查，发现CDG和CDH的闭包是U。
   -  CDG  和  CDH 。  


**3NF分解（无损且保持依赖）**    
为每个函数依赖创建子模式：  
        -  $R_1(A,B)$ （覆盖  A→B ）  
        -  $R_2(B,E)$ （覆盖  B→E ）  
        -  $R_3(C,D,B)$ （覆盖  CD→B）  
        -  $R_4(C,D,E,A)$ （覆盖  CDE→A ）  
        -  $R_5(G,A)$ （覆盖  G→A ）  
        -  $R_6(H,G)$ （覆盖 H→G G→H ）  
包含候选键的子模式：  
        -  $R_7(C,D,G)$ （确保无损连接）。  
**分解结果**：  
     \[
      \{ R_1(A,B), R_2(B,E), R_3(C,D,B), R_4(C,D,E,A), R_5(G,A), R_6(H,G), R_7(C,D,G) \} .
     \]
